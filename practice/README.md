# Practice Guide Overview

This page brings together the practical lab files for the course. Instead of linking the main course notebooks, it points to the exercise and practice guides in the practice folder.

## 01 - Spam / Adversarial Text

These practice files build a spam filter from the ground up and then stress-test it with adversarial examples.

- [spam/guide_02_01.ipynb](spam/guide_02_01.ipynb) — Build a spam filter from scratch with Naive Bayes, TF-IDF, and logistic regression.

<div style="page-break-after: always;"></div>


- [spam/guide_02_02.ipynb](spam/guide_02_02.ipynb) — Compare word vectors, sentence embeddings, and llama.cpp-based embeddings for the same spam task.

<div style="page-break-after: always;"></div>


- [spam/guide_02_03.ipynb](spam/guide_02_03.ipynb) — Find counterexamples, useful adversarial spam, and defenses that keep the filter robust.

<div style="page-break-after: always;"></div>


## 02 - Anomaly Detection

These guides focus on building and attacking anomaly detectors for network traffic and temporal patterns.

- [anomaly/guide_03_01.ipynb](anomaly/guide_03_01.ipynb) — Classic anomaly detectors on network connections: z-score, Mahalanobis distance, thresholds, and KDD99 evaluation.

<div style="page-break-after: always;"></div>


- [anomaly/guide_03_02.ipynb](anomaly/guide_03_02.ipynb) — Autoencoders, time-series anomalies, and reconstruction-based detection in an adversarial setting.

<div style="page-break-after: always;"></div>


- [anomaly/guide_03_03.ipynb](anomaly/guide_03_03.ipynb) — Test anomaly detectors as an adversary would: evasion, mimicry, poisoning, and robust defenses.

<div style="page-break-after: always;"></div>
